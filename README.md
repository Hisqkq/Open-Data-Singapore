## ✨ Features

- **Dynamic visualisations** powered by Plotly & Dash.
- **Three thematic pillars**: **Education**, **Housing**, **Economy**.
- **Predictive model**: estimate the resale price of an HDB flat in real‑time.
- **Responsive design**: works on desktop & mobile.
- **Statistical highlights** autogenerated for each dataset.


## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Front‑end | Dash, Plotly, Dash Mantine components |
| Data | Pandas, data.gov.sg APIs, CSV snapshots |
| ML | scikit‑learn, Catboost |
| Deployment | Render (free tier), Gunicorn |

## 🚀 Quick Start

```bash
# 1. Clone
git clone https://github.com/Hisqkq/Open-Data-Singapore.git
cd Open-Data-Singapore

# 2. (Optional) create virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run locally
python app.py
```

Then open <http://127.0.0.1:8050> in your browser.
